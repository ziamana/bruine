## 3. Web search (`tool-web` `search`)
There is NO fully local web search (a search needs an index of the web). Setup offers:
`none (default) | SearXNG instance URL (self-hosted, e.g. http://localhost:8888) | Brave Search API key | Tavily API key`.
Do NOT ship dsh-free-search (it scrapes Bing without an agreement: not acceptable in a public product).
If a local SearXNG answers on localhost:8888 / 8080 during setup, propose it.
