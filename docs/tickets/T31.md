# T31 — Slash command palette + `/new` (minimum for the first release)

## 1. Typing `/` opens the command list
pi-tui already ships it: `CombinedAutocompleteProvider(commands, basePath)` in `@earendil-works/pi-tui/dist/autocomplete`
(`SlashCommand { name, description }`), used by pi. Wire it on kumo's Editor.
```
  › /
    /new           Start a new conversation
    /compact       Summarize the conversation to free context
    /plan          Toggle Plan mode (also Tab)
    /permissions   Choose Ask / Auto / Full access (also Shift+Tab)
    /skills        List the enabled skills
    /help          Show commands and keys
    /exit          Quit kumo (also ctrl+d)
```
- Opens as soon as `/` is the first character; fuzzy filter while typing (`/co` → `/compact`); ↑↓ move; Enter runs;
  Esc closes the list and keeps the text.
- **Tab while the list is open completes the command** (it does not toggle Plan). Tab toggles Plan only when the list
  is closed.
- Source of truth: kumo's own commands + every command registered in dsh's `commands` service (`dsh-commands`), with
  their description. No duplicate names; kumo's wins.
- Unknown command: notice `Unknown command /xyz. Type / to see the list.`, nothing sent to the model.

## 2. `/new`
- Waits for the current turn to finish or asks `A reply is running. Stop it and start a new conversation? (y/N)`.
- Flushes the current session (`sessions.flush`), creates a NEW agent with a new session id (same model, mode, plan
  state reset to Build, same skills), clears the chat, redraws the header, notice `New conversation.`
- Footer context back to 0 %, TPS reset, cache meter gray (first call).
- The old session stays on disk (a later `/resume` can use it; not in this ticket).

## 3. `/help`
Prints, in the chat (dim, not sent to the model): the command list above + the keys
(Esc interrupt, ctrl+c clear, ctrl+d exit, Tab Plan, Shift+Tab permissions, → accept suggestion, ctrl+o expand tools).
