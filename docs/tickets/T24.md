# T24 — Finishing touches (small, mechanical)

## Files
`src/**` (string literals only for part 1), `skills/**`, `README.md` if present, `src/ui/**`, `src/plugins/render.ts`,

## 1. No em-dash `—` in anything a user reads
Product rule (Aron): the em-dash makes text look machine-written. **Every user-visible string** and every shipped
`skills/*/SKILL.md` must use `:` `,` `(…)` or a period instead. ~30 strings today (`src/setup/full.ts`, `simple.ts`,
`bin.ts`, `discover.ts`, `flow.ts`, `footer.ts`) + the 4 skills. Examples:
- `"Ask (default) — confirm every command and write"` → `"Ask (default): confirm every command and write"`
- `"Setup canceled — run \`kumo setup\` when ready."` → `"Setup canceled. Run \`kumo setup\` when ready."`
- footer `"0%/— (auto)"` → `"0%/? (auto)"`
Code comments may keep it. New test `test/style.test.ts`: no `—` inside any string/template literal in `src/**/*.ts`
(strip comments first) and none in `skills/**`.

## 2. Mode announcements are not user messages
The Plan/Build/Ask/Auto/Full announcement appended to the context (cache rule: stays a message) is echoed in the chat
as if the user typed it: `› Plan mode is on: …`. Render it as a dim one-line system note without `›`, e.g.
`  · plan mode on`. The message sent to the model does not change (T17 must stay green).

## 3. Piped (non-TTY) output must not animate
`echo hi | kumo` writes every spinner frame (`· Thinking· Thinking✢ Thinking…`) into the log. When stdout is not a TTY:
no spinner, no in-place rewrite. Print only `Thought for 0.4s` once, then the answer.

## 4. E2E screens must not dirty git
Running `pnpm test:e2e` rewrites the committed `__screens__/*.txt` (temp dir names, timings). Write run screens to a
git-ignored `test/e2e/__screens__/run/` instead. The committed before/after screens stay as documentation.

## Acceptance
- `pnpm test` and `pnpm test:e2e`, then `git status --short` prints nothing.
- `grep -rn "—" skills` prints nothing; the style test passes.
- Piped run: output contains no spinner glyph and no `\r`.
- E2E: after Tab, no line starting with `›` contains "mode".
