# T05 — Tool call renderer

## Goal
Stream tool calls like pi: a header that fills in while arguments arrive, then a result line with a short output preview.

## Files
- `src/render/tools.ts`
- `test/tools.test.ts`

## Spec
```ts
export class ToolCallView {
  constructor(screen: Screen, now?: () => number)          // Screen from render/reasoning.ts
  start(id: string, toolName: string): void
  args(id: string, jsonDelta: string): void                // streamed JSON argument text
  result(id: string, ok: boolean, output: string): void
}
```
- `start` → writes `● <toolName>` (no newline yet), records start time.
- `args` → accumulate raw text; redraw header `"\r\x1b[2K● <tool>  " + summary`, where summary =
  - if accumulated text parses as JSON: the value of the first key among `command, cmd, path, file_path, url, query, pattern`; else the compact JSON; truncated to `columns - tool.length - 6` with `…`.
  - if it does not parse yet: `…` (still streaming).
- `result` → `"\r\x1b[2K" + (ok ? "✓" : "✗") + " <tool>  <summary>  <s>s\n"`, then up to 5 lines of `output`, each dim and indented 4 spaces; if more lines, one dim line `    … N more lines`.
- Unknown `id` in `args`/`result` → ignored silently (no throw).

## Acceptance
1. start("1","bash"), args `{"comm`, args `and":"ls -la"}`, result ok "a\nb" → final header `✓ bash  ls -la  …s` and two dim lines `a`, `b`.
2. output of 12 lines → 5 lines shown + `… 7 more lines`.
3. `{"path":"src/x.ts"}` → summary `src/x.ts`.
4. result with ok=false → starts with `✗`.
5. unknown id → no throw, no write.
