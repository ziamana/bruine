# T17 — Cache Hunter test: prove the prompt cache is never broken

Idea from youtu.be/AkwItxJ9AbA. A CI test, not a manual check.

## Files
- `test/cache/fake-server.ts` (OpenAI-compatible fake that RECORDS every request body)
- `test/cache/cache.test.ts`

## Scenario (scripted, against the fake server that returns canned tool calls / text)
1. Plan mode, ask for a plan → switch to Build → implement (2-3 tool calls)
2. Add a skill file → ask to use it
3. Edit AGENTS.md → ask a question about it
4. Toggle Ask / Auto / Full access
5. `/compact`

## Assertion
For every consecutive pair of requests in the main session: request N+1's `system` + `tools` are **byte-identical**
to request N's, and request N's messages are a **prefix** of request N+1's messages (except right after compaction,
where only `system` + `tools` must match). Print the first differing byte on failure.
