# T35 — `kumo setup` on an existing install: see what is there, change one thing, skip the rest

Aron (2026-09-26), running `kumo setup` on his working install: "dans le setup fais des options skip par pitié".
Real screen: the Models step lists only `+ Enter a server address…`, `+ Scan your local network`,
`Continue → (cloud models only)`. **His working server (192.168.1.64:8081, in settings.yaml) is not shown**: the
prefill reads kumo.json only. A user who just wants to change the theme must redo everything.

## 1. Prefill from settings.yaml (source of truth, like T31b)
Every route in `llm-pi-ai.providers` with its models appears in the Models step as `✓ Ornith 1.5 9B · 192.168.1.64
(current)`, preselected. Roles prefilled from `agent-default-model` + kumo.json `models`. Keep existing `compat`,
`reasoningEfforts`, `contextWindow`, `name` untouched when the user does not change that route.

## 2. Existing install → a menu, not the linear wizard
If settings.yaml has a default route, `kumo setup` opens:
```
  kumo setup: what do you want to change?
  → Models          Ornith 1.5 9B · 192.168.1.64
    Default mode    Auto
    Web search      none
    Skills          12 enabled
    Theme           dark
    Telemetry       off · update check on · suggestions on
    Save and exit
    Quit without saving
```
Picking a line runs only that step, then comes back to the menu with the new value shown. `Save and exit` writes
once (atomic, as today). First install keeps the linear wizard.

## 3. Skip everywhere in the first-install wizard
Every step has a last item `Skip (keep: <current or default>)` and the key `s` does the same. The Models step on a
first install can only be skipped if at least one model exists.
