# T38 — f2 walks the recent routes, and the effort follows the model

T37 leaves two loose ends that are not the picker's business, so they are their own ticket.

## 1. f2 = the next recently used route
OpenCode has `model_cycle_recent` on `f2`; kumo takes the key and drops the rest. pi-tui 0.85.1 has
**no `shift+f2` sequence in any protocol** (`LEGACY_SEQUENCE_KEY_IDS` has F1-F4 unshifted only, and the
Kitty CSI-u form for a function key is not matched either — measured with `matchesKey`), so no reverse
bind is claimed. `cycleRecent(step)` keeps the direction parameter as the API; only `f2` is a key.

The recents live in `kumo.json` as `recentModels: string[]` of `provider/model`, written atomically at
`0600` with a unique temp name (the `persistLevel` pattern, T34). **Both the route taken and the route
left are recorded**, newest first: a user who switches once must be able to switch back, and the model
they came from was never in the list. (Measured bug: with only the new route recorded, f2 answered
"No other recent model yet" right after a successful switch.)

A remembered entry is skipped when its provider is gone, or when its model is no longer declared on
that route — it could not be dispatched, so cycling to it would only produce a failed turn.

## 2. `Effort.adoptRoute(provider, model)`
T34's `Effort` caches the levels of the model in use. A route switch leaves them stale: ctrl+e would
offer `xhigh` to a model that has no such level, and the footer would keep naming the old model's
switch. `attach`'s body is split into a private `resolveLevels(provider, model, llm)`, used by both
`attach` and `adoptRoute`. Priority: a live effort the new model still offers (an explicit choice
survives a switch), else the level saved for that model, else the T34 default; nothing left → `auto`.
A model with no thinking switch therefore ends on `auto`, never on a stale wire value.

## Acceptance
- Unit: after one switch, `recentModels` holds `[new, previous]` and one `cycleRecent(1)` returns to the
  first model; a refused switch writes no kumo.json at all.
- Unit: the key listener claims `f2` (`\x1bOQ`, `\x1b[12~`) and returns `{}` for `\x1b[1;2Q` and for a
  plain letter — no reverse bind is advertised.
- Unit: `adoptRoute` re-resolves the levels, keeps a still-offered live effort, drops one the new model
  does not have, and leaves `reasoningEffort` undefined for a model with no thinking at all.
- Unit: the whole T34 suite still passes unchanged (a boot must behave exactly as before).
- E2E: `/model` to the second model, `f2`, and the next recorded body carries the first model again.
