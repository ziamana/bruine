# T06 — Text renderer

## Goal
Stream the assistant's answer text cleanly, never colliding with the reasoning line.

## Files
- `src/render/text.ts`
- `test/text.test.ts`

## Spec
```ts
export class TextStream {
  constructor(screen: Screen)
  push(delta: string): void
  end(): void              // ensures the output ends with exactly one "\n"
}
```
- First `push` of a turn writes `"\r\x1b[2K"` first (clears whatever temporary line was there).
- Writes deltas as-is.
- `end()`: if the last written char is not `\n`, write `\n`. Resets so the next `push` is "first" again.

## Acceptance
1. push("Hel"), push("lo") , end() → concatenated writes = `"\r\x1b[2KHello\n"`.
2. push("Hi\n"), end() → no extra `\n`.
3. end() with no push → no write.
