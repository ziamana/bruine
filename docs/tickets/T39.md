# T39 — `/provider`: every provider, its endpoint, its key, its models

The question behind T37: *"is there a /provider that shows all the providers?"* This is that command,
and it is **read-only**: it never writes settings.yaml, never writes a key, never adds a route. Adding
a provider is `kumo setup`'s job (T21/T35) and the answer here always ends with it.

## 1. The list
For every route: display name and id, `(current route)` on the provider in use, the endpoint
(`baseURL`), the key state (`key OPENROUTER_API_KEY set` / `no OPENROUTER_API_KEY`), how many models
the route declares, and any configuration diagnostic dsh reported for it. Key state reads the key
**name** from `$DSH_HOME/.env` (and `process.env`); a value never leaves the reader. A route with no
`apiKeyEnv` is a local server, which pi-ai ignores the value of.

## 2. The directory is counted, not dumped — `/provider all` prints it
`llm.listConfigurableProviders()` returns pi-ai's whole provider directory: **~60 dormant entries**
(minimax, openai, anthropic, xai, zai, qwen-token-plan, …). Measured on the e2e harness: printing them
all buried the two usable rows and pushed the answer off a 30-row screen. So:

- `/model` never lists a dormant route — it cannot be dispatched, and the picker already answers
  "run kumo setup" for a route dsh has not mounted;
- `/provider` prints the mounted and declared routes in full, then
  `+ 39 more kumo can add (deepseek, openrouter, openai, anthropic, google, xai, ...)` and
  `/provider all lists them`;
- `/provider all` prints every entry, which is the answer to "show me everything kumo can drive".

## 3. The non-TTY path is the same text
No picker, no dialog: the same lines through the router's `reply`, so a piped session and a test can
read it.

## Files
`src/plugins/model.ts`, `src/plugins/repl.ts` (router + `/help`), `test/t37-model.test.ts`,
`test/e2e/**`.

## Acceptance
- Unit: `/provider` names every mounted and declared route with its endpoint, key state, model count and
  the current marker, and settings.yaml is byte-identical afterwards.
- Unit: with a runtime whose `listProviders`/`listConfigurableProviders` throw, the command answers
  instead of crashing.
- Unit: plain `/provider` counts the dormant directory and stays short; `/provider all` lists it.
- E2E: `/provider` shows the local route with `key KUMO_LOCAL_API_KEY set` and `In use: local/e2e-model`
  (assertions use fragments that cannot straddle a 100-column wrap).
