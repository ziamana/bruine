# T04 — Reasoning line renderer  ★ signature feature

## Goal
Show the model's reasoning as ONE dim line that is rewritten in place:
text accumulates on the line; each `\n` in the stream finishes the line and the next line replaces it.
When reasoning ends, the line becomes `💭 thought for 4.2s`.

## Files
- `src/render/reasoning.ts`
- `test/reasoning.test.ts`

## Spec
```ts
export interface Screen { write(s: string): void; columns: number }
export class ReasoningLine {
  constructor(screen: Screen, now: () => number = Date.now)
  push(delta: string): void   // a reasoning-delta chunk (may contain 0..n "\n")
  end(): void                 // reasoning block finished
  get active(): boolean
}
```
Rules:
- First `push` with non-empty text: record start time, `active = true`.
- Keep `current` = text after the last `\n` seen. Every `push` redraws: `"\r\x1b[2K" + dim("💭 " + visible(current))`.
  - `dim(s)` = `"\x1b[2m" + s + "\x1b[22m"`.
  - `visible(s)`: trim leading spaces; if longer than `columns - 4`, keep the LAST `columns - 5` chars prefixed with `…`.
- If `current` is empty right after a `\n` (next line not started yet), keep showing the previous finished line until new text arrives (no blank flicker).
- `end()`: `"\r\x1b[2K" + dim("💭 thought for X.Ys") + "\n"`, where X.Y = seconds rounded to 1 decimal; `active = false`.
- `end()` when never active → writes nothing.
- Empty `push("")` → writes nothing.

## Acceptance (fake Screen collecting writes, fake clock)
1. `push("Let me"), push(" check")` → last write shows `💭 Let me check`.
2. `push("line one\nline t")` → last write shows `💭 line t` (not "line one").
3. `push("done\n")` then nothing else → still shows `💭 done`.
4. columns = 20 and a 50-char line → visible part ≤ 16 chars and starts with `…`.
5. start at t=1000, end at t=5200 → `💭 thought for 4.2s` followed by `\n`.
6. `end()` without push → zero writes.
