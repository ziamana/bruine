## 1. Never echo the API key (security)
`io.question(keyPrompt)` uses readline, so the key is printed in clear while typed
(it stays in the terminal scrollback and in any screen recording).
- Add `SetupIO.secret(prompt): Promise<string>` : raw mode on stdin, print `*` per char, handle Backspace, Enter, Ctrl+C (exit 130).
- Use it for the API key. Non-TTY: read one line from stdin without echo.
- Test: a fake IO whose `secret` is called for the key and `question` is NOT called for it.

## 2. `--help` / `--version` only as the FIRST argument
Today `kumo "explain the --help flag"` prints the usage instead of asking the model.
- Intercept only when `argv[0]` is `--help`, `-h`, `--version`, `-V`.
- Test both cases.

## 3. Check how the bundle is installed into the profile
`dsh plugin --profile kumo add <repo path>` → verify whether pnpm links the repo or copies it:
`readlink -f ~/.kumo/profiles/kumo/node_modules/kumo-cli`.
- If it is a COPY: add `kumo dev-link` (or document it) so that `pnpm build` in the repo is picked up without reinstalling.
- Report what you found in the final message.
