# T57 — The answer is revealed, not token by token

## The problem
`AssistantTextComponent.push` set the whole accumulated text on pi-tui's
Markdown component on **every delta**. A local model on the 3070 delivers 60 to
200 tokens a second, so the paragraph was re-laid-out dozens of times a second:
the line under the reader's eye moved before it was read, and a `**bold**` was
painted as literal asterisks for a few frames each time. That is not streaming,
it is a seizure with a text cursor.

The characters are all there already. The bug is that arrival and display were
the same event.

## What it does
Text is buffered and handed out on a 40 ms clock (25 frames a second, well above
pi-tui's 16 ms repaint floor). Four rules, each one a bug this had first:

- **Catch up, do not crawl.** The step is 18% of the backlog, not a fixed number
  of characters, so the lag settles around a fifth of a second at any model
  speed. A fixed rate falls behind a fast model forever and makes it look broken.
- **A grapheme is atomic.** An emoji is two code units; a step that lands
  between them takes the whole emoji rather than refusing to move.
- **Half a markdown marker is held, briefly.** `**b` with its pair still in the
  buffer paints two literal asterisks. The reveal waits, for at most 4 ticks
  (about 160 ms).
- **Never stop.** Every guard has a budget: a marker 48 characters back is
  treated as prose, and a marker at the frontier is let out after the budget. A
  guard that can wait forever is a freeze, and a marker sitting exactly at the
  frontier can only be held by not moving.

`finish()` flushes: a turn never ends with text still hidden.

## The switch
`KUMO_NO_ANIMATION=1` turns it off, and so do CI, a non-tty stdout, `TERM=dumb`
and `KUMO_ASCII=1`, through the same gate the wordmark sweep and the Waiting dots
already use (`terminalMotionAllowed`). One switch, every moving thing. Off means
every delta is painted the moment it lands, which is exactly the old behaviour,
so nothing else in the product depends on it.

## Out of scope, on purpose
- The reasoning stream (`ReasoningComponent`) keeps its own reveal. A second
  animated block on the same screen is noise, and reasoning is collapsed by
  default anyway.
- Per-character cursor, sound, a "typewriter" font. kumo does not draw inside
  the line it is writing.
- Speeding the reveal up or slowing it down from the config. One honest default
  beats a knob nobody turns.

## Acceptance
- With no repaint hook, every delta is visible immediately: the disabled path is
  byte-identical to the renderer it replaces.
- One tick hands out a share of the backlog, never all of it, and the reveal ends
  on its own.
- Every intermediate frame is a whole number of graphemes: a lone surrogate
  never reaches the screen, including a ZWJ family.
- A half-open `**` is held, and released the moment the pair arrives.
- A marker that never closes, and a lone `*` in prose, cannot stop the answer.
- The component repaints on every step of the reveal, not only on arrival.
- `finish()` leaves nothing hidden.
