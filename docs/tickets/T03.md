# T03 — Profile generator

## Goal
Create (idempotently) the dsh profile kumo boots: `<DSH_HOME>/profiles/kumo/`.

## Files
- `src/profile.ts`
- `test/profile.test.ts`

## Spec
`export async function ensureProfile(dshHome: string): Promise<{ created: boolean; dir: string }>`
- dir = `<dshHome>/profiles/kumo`
- If `dir/package.json` exists → return `{ created: false, dir }` and change NOTHING (user edits must survive).
- Else create `dir` recursively and write:
  - `package.json`:
    ```json
    { "name": "dsh-profile-kumo", "private": true,
      "dependencies": { "kumo-cli": "<version of this package>" },
      "dsh": { "profile": { "bundles": ["@deepseek-ai/dsh-base", "kumo-cli"], "patchReload": "startup" } } }
    ```
  - `cordis.patch.yml`: a comment line `# kumo user overrides. Edit this file, not cordis.yml.` then `[]`
  - `cordis.yml`: a comment line `# managed by dsh, do not edit` then `[]`
- Write files atomically (write to `.tmp` then rename).

## Acceptance
- On an empty temp dir: `created: true`, the 3 files exist, `package.json` parses and has the 2 bundles.
- Second call: `created: false`, and a byte-for-byte check shows `cordis.patch.yml` untouched after the test modifies it between the two calls.

## Out of scope
Installing node_modules into the profile (done later by `dsh plugin`).
