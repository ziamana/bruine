## UI
- `todo_write` calls are NOT shown as tool lines. Instead, a **task panel** sits between the chat and the editor,
  visible while the list has at least one non-completed item:
```
  Tasks  2/5
  ✓ Read the launcher
  ✓ Find where the footer is drawn
  ✻ Add the cache meter            ← spinner frames (T23) on in_progress items
  ○ Update the tests
  ○ Run the e2e suite
```
- Colors: completed dim with `✓` green, in_progress bright with the spinner, pending `○` normal.
- Max 7 lines: if more, show the in_progress ones + neighbors and `… 4 more` ; `ctrl+t` toggles the full list.
- When every item is completed: the panel collapses into one dim chat line `✓ 5 tasks done` and disappears.
- `/new` clears it. A resumed session rebuilds it from the last `todo_write` (last write wins).
- Piped mode: print `Tasks 2/5` + the list once per change, no spinner.
- Add `ctrl+t` to `/help`.
